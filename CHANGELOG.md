# Changelog

All notable changes to OpenDJ are managed via [Changesets](./.changeset/).

Each `@opendj/*` package maintains its own `CHANGELOG.md` (generated on release). This root file links to per-package changelogs once the first release is cut.

Until the first release, see [`git log`](https://github.com/viscoci/opendj/commits/main) for history.
